# Brain Voice Messenger

A phone-first, installable web app that speaks typed messages aloud.

## Publish with GitHub Pages

1. Open the repository **Settings**.
2. Choose **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main**, folder **/(root)**, then click **Save**.
5. After GitHub finishes publishing, open: `https://gawd71730.github.io/brain-voice-messenger/`

## Install on Brain's phone

- **iPhone:** open the published link in Safari, tap Share, then **Add to Home Screen**.
- **Android:** open the published link in Chrome, use the browser menu, then **Install app**.

The app uses the phone's built-in speech voice. It offers voice, speed, pitch, volume, and offline caching after the first visit.
